# Тесты конфигурации

Проверяют, что конфиг не сломан: стиль кода, отсутствие предупреждений Lua,
подключение языковых серверов и работа форматтеров.

## Запуск

```sh
~/.config/nvim/tests/run.sh
```

Код возврата `0` — всё в порядке, `1` — есть провалившиеся проверки.

## Что проверяется

| Группа | Что именно |
|---|---|
| Стиль и статический анализ | `stylua --check` по всему конфигу, `lua-language-server --check` на предупреждения |
| Плагины | каждый ожидаемый плагин есть в списке lazy.nvim |
| Пакеты Mason | всё из `ensure_installed` установлено |
| Системные инструменты | `rust-analyzer` и `rustfmt` берутся из `~/.cargo/bin`, а не из Mason; `mix` и `fish_indent` находятся в PATH |
| Парсеры Treesitter | парсеры для всех рабочих языков установлены |
| Языковые серверы | для каждого языка определяется тип файла и подключается нужный сервер |
| Форматирование | для каждого языка выбирается нужный форматтер, а результат совпадает с эталоном |

## Файлы

- `run.sh` — точка входа: сначала внешние проверки, потом запуск Neovim
- `init.lua` — склейка, вызывается внутри headless Neovim
- `fixtures.lua` — создаёт временные проекты и хранит эталоны форматирования
- `spec.lua` — сами проверки и вывод

Временные проекты создаются в каталоге из `vim.fn.tempname()` и не трогают
твои реальные файлы.
